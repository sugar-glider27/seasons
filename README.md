# seasons

So far, we have explored the CMIP6 climate data and created static visualizations to brainstorm different ideas. We decided to focus on how seasonal temperatures change across different locations and years. On our website, we have implemented an interactive globe alongside a line graph comparing temperature changes across the four seasons. As we scroll through the website, the globe automatically shifts between different regions and the graph updates to show how seasonal warming varies at that location. The globe is an important part of our narrative because we plan to make it rotatable, allowing users to select different locations and explore how seasonal warming varies by region.

The most challenging part of our project is integrating the interactive transitions and animations that connect our narrative seasonal elements with the globe’s locations and time of year. This is because our team aims to design background special effects that guide the user through each season, but that requires strong artistic creativity to ensure that it is easy to engage and navigate. If users switch between different environments around the world quickly, our interface and effects both need to be responsive, without noticeable delays. The navigation bars and text annotations should be easily accessible, with tooltips and descriptive features that offer users additional information, such as the areas’ temperature and changes over time.
